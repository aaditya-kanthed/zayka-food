# ZAYKA - 100% Vegetarian Online Food Ordering Platform

## 1. Introduction
Zayka is a comprehensive online food ordering platform specifically catering to 100% pure vegetarian diets. It aims to deliver authentic, healthy, and high-quality vegetarian comfort food, ranging from North and South Indian thalis to specialized diets like Vegan, Jain, Keto, and High-Protein (Gym) meals. The platform emphasizes "Shuddh Swad" (pure taste) by offering meals cooked with organic ingredients and zero artificial flavors, providing a seamless and highly personalized user experience from menu browsing to checkout.

## 2. Problem Statement
Finding pure, authentic, and hygienic vegetarian food online can often be challenging, especially for users with strict dietary preferences such as Jain (no onion/garlic), Sattvic, or fitness-oriented (High Protein/Keto) diets. Many existing food delivery apps clump all cuisines together, making it difficult for pure vegetarians to filter out concerns or find purely vegetarian-focused kitchens. Furthermore, users often struggle with the daily "what to eat" dilemma and lack automated, tailored meal planning solutions based on their mood, dietary restrictions, and nutritional needs.

## 3. Solution Domain
To address these issues, Zayka focuses exclusively on the vegetarian food domain. The solution is a responsive, feature-rich web platform that not only allows users to browse and order various vegetarian meals but also features an innovative "AI Meal Helper." This helper recommends perfectly suited meals based on user inputs (mood, diet preference, craving). Additionally, the solution provides a "Weekly Meal Planner" to automate user diet schedules, seasonal/festival promotional offers, and a highly accessible interface with features like dark mode and an interactive cart system.

## 4. Tools and Tech Used
- **Frontend Core:** HTML5 (Semantic Structure), CSS3 (Styling, Flexbox/Grid Layouts, Animations), Vanilla JavaScript (ES6+ for interactive logic, DOM manipulation).
- **Design & UI/UX:** Responsive Web Design, CSS Custom Properties (Variables) for theming, Dark/Light Mode toggle option.
- **Typography & Assets:** Google Fonts (Rubik), Ionicons library for scalable vector icons, custom imagery.
- **Functional Features:** Dynamic meal filtering/search system, client-side cart calculation, AI mock-recommendation engine, countdown timers for festive offers.

## 5. Result
The resulting platform is an intuitive, fast, and visually appealing web application. Users can seamlessly navigate between sections, toggle visual themes, dynamically filter the menu based on complex dietary needs, add items to their cart, and get instant subtotal calculations. The AI helper successfully intakes user constraints to display real-time curated meal suggestions, improving engagement and solving the decision-fatigue problem for users.

## 6. Conclusion
Zayka successfully bridges the gap between pure vegetarian lifestyle requirements and modern convenience. By combining traditional culinary values with contemporary web features like personalized AI recommendations, dynamic filtering, and a sleek user interface, it provides a superior alternative to generic food delivery platforms for the vegetarian demographic. The user-centric design ensures that from craving to checkout, the journey is smooth and delightful.

## 7. Application of this Project
- **Independent Cloud Kitchens/Restaurants:** Can be adopted by specialized vegetarian restaurants as their direct-to-consumer ordering portal.
- **Dietary & Nutrition Services:** Can be used by nutritionists partnering with kitchens to provide specific weekly meal plans (Vegan, Keto, Gym) directly to clients.
- **Academic / Portfolio Use:** Serves as a strong showcase of frontend development skills, including advanced CSS layouts, JavaScript functionality without heavy frameworks, and modern UI/UX principles.
